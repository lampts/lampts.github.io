Revenue Forecasting via Monte Carlo Simulation

Ridge-regularized autoregressive time series with empirical bootstrap noise sampling

Interactive Tool · Updated November 2025

Traditional forecasting relies on point estimates that obscure uncertainty. This tool runs thousands of simulations to generate probability distributions of outcomes, revealing expected values and tail risks through ridge-regularized autoregressive modeling with empirical residual bootstrap.

The autoregressive model captures temporal dependencies: yesterday's performance predicts today's, weekly patterns repeat, trends persist. Features include lag₁ (daily momentum), lag₃ (mid-week), lag₇ (weekly seasonality), lag₁₄ (bi-weekly), and MA7 (rolling average). Ridge regression prevents overfitting with L2 penalty. Noise is sampled from actual prediction errors to preserve skewness and tail behavior.

How It Works: Core Prediction Formula

revenuet = w₁·lag₁ + w₃·lag₃ + w₇·lag₇ + w₁₄·lag₁₄ + wma·MA7 + bias + ε

Feature Breakdown:

  • lag₁ = revenuet-1 — Yesterday's value (daily momentum)
  • lag₃ = revenuet-3 — Three days ago (mid-week pattern)
  • lag₇ = revenuet-7 — Same weekday last week (weekly seasonality)
  • lag₁₄ = revenuet-14 — Two weeks ago (bi-weekly cycles)
  • MA7 = mean(revenuet-7:t) — Rolling 7-day average (trend)
  • bias = constant offset (baseline level)
  • ε ~ Bootstrap(residuals) — Empirical noise sampled from actual errors

Weights (w₁, w₃, w₇, w₁₄, wma): Learned from data via ridge regression. Indicate feature importance.

Bootstrap Noise Sampling: Why It Matters

✓ Bootstrap vs Gaussian Noise

Traditional approach (Gaussian): Assumes errors ~ N(0, σ) — symmetric, thin tails, no skewness.

Bootstrap approach (this model): Samples from actual residuals — preserves skewness, fat tails, and real error distribution.

Revenue data is typically right-skewed (big days happen more often than big drops). Bootstrap captures this asymmetry for more accurate risk estimates.

Concrete Example: Impact of Distribution Shape

# Typical residuals from ridge model
residuals = [-8.2, -6.1, -4.3, ..., +7.3, +9.1, +12.4]  # Right-skewed
mean(residuals) = 0.0
std(residuals)  = 5.34  ← Same σ, different shape!
skewness = +0.73  ← More large positive errors than negative

# Gaussian sampling (ignores skewness)
noise ~ N(0, 5.34)
P(noise > +10) = 3.0%  ❌ Underestimates big days

# Bootstrap sampling (preserves skewness)
noise ~ random_choice(residuals)
P(noise > +10) = 8.4%  ✓ Matches reality

Impact on forecast:
  Gaussian:   P(revenue > 80) = 1.2%
  Bootstrap:  P(revenue > 80) = 3.8%  ← More realistic

Monte Carlo Sampling: The Complete Formula

Each simulated day combines three multiplicative factors:

simulated_revenuet = ridge_predictiont × boost_factort × downtime_factort

① Ridge Prediction

base = w·X + εbootstrap

Autoregressive forecast from historical patterns + empirical noise from residuals

② Boost Factor

boost ~ U(1.05, 1.15)

Applied on event days (Black Friday, promotions)

③ Downtime Factor

impact ~ U(0.90, 0.95)

Random outages with probability P = 1/period_length

Step-by-Step Sampling Process

# Simulation loop for each remaining day
for day in [current_day + 1, ..., period_end]:
    for simulation in range(n_simulations):
        
        # STEP 1: Ridge prediction with bootstrap noise
        features = [lag₁, lag₃, lag₇, lag₁₄, MA7, 1.0]
        base_prediction = dot(weights, features)
        
        # Sample noise from actual residuals (with replacement)
        noise = random_choice(residuals)  # Bootstrap!
        ridge_pred = base_prediction + noise
        
        # STEP 2: Apply boost if event day
        if day in event_days:
            boost_factor = Uniform(1.05, 1.15)  # 5-15% boost
        else:
            boost_factor = 1.0
        
        # STEP 3: Apply downtime with probability
        if random() < P(downtime):  # P = downtimeEvents/periodLength
            downtime_factor = 1 - Uniform(0.05, 0.10)  # 5-10% drop
        else:
            downtime_factor = 1.0
        
        # COMBINE: Multiplicative formula
        revenue = ridge_pred × boost_factor × downtime_factor
        revenue = max(0, revenue)  # Non-negative constraint
        
        # Store for next iteration (autoregressive dependency)
        history[day] = revenue
