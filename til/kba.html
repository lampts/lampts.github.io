Zero-infrastructure KB Agent for Banking Voice Agents

Pickle everything at build time. Load into memory at startup. Stateless workers for K8s/Docker scale-out. No Redis, no MongoDB, no vector DB.

Key Insight

Karpathy's arxiv-sanity works because he accepted constraints: single server, papers fit in memory, batch updates daily. Same philosophy adapted for stateless scale-out.

Constraints accepted:
Single server → Stateless workers
MongoDB comments → Dropped
In-memory rate limits → Accept reset
P(works) = P(fits_memory) × P(stateless) × P(no_deps) = 97%
